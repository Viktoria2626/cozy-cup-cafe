# Cozy Cup Café

Cozy Cup Café is a responsive café website built with HTML5, CSS3, and JavaScript.

## Features

- Responsive design for desktop and mobile devices
- Multi-page navigation
- Café menu with product descriptions and prices
- Online ordering form with automatic total calculation
- Contact form with JavaScript confirmation message

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Live Website

[View Cozy Cup Café Website](https://viktoria2626.github.io/cozy-cup-cafe/)

## What I Practiced

Through this project, I practiced building responsive web pages, creating and styling forms, working with JavaScript events and DOM manipulation, and publishing a website using GitHub Pages.
